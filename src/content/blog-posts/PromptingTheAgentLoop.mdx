I have seen lots of people offering Claude Code tips, but I think there's only one piece of advice which matters. You need to prompt the loop.

Agent was meaningless jargon until earlier this year when the industry standardized around the [standard definition](https://simonwillison.net/2025/Sep/18/agents/) of "a language model which runs tools in a loop to achieve a goal." You will get way more value out of AI tools if you understand how to control agents through the loop.

## What is This Loop You Speak Of?

Consider the contrived example of asking claude code "add a new function to the `index.ts` file called `sum` which accepts an array of numbers and returns the result of adding them all together". Sounds clear and like it should work right? WRONG! Watch the output below.

Our prompt isn't giving the agent anything to test its changes with, so it's bound to miss some things. You want something more like "look at @index.ts and start by making sure you have a way to unit tests functions which get added to that file. Add jest and new ts files if you need to, add a new script to @package.json. Then scaffold a new sum function in @index.ts, write robust tests for it, run them, watch them fail, implement thr sum function until they all pass." Watch *this baby* run!
